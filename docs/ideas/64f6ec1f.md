## Context
The spec designer can work from an existing spec, but currently lacks the edit tool needed to make selective targeted changes in-place.

## Goal
Allow the spec designer to take an existing spec and apply precise, targeted edits rather than rewriting or relying on broader file operations.

## Scope
- Review the spec designer agent/tool configuration.
- Enable access to the edit tool where appropriate.
- Preserve safeguards and expected workflow for spec creation and refinement.
- Ensure existing-spec editing remains selective and targeted.

## Acceptance Sketch
- The spec designer can open an existing spec and use the edit tool to replace specific text ranges.
- Existing spec workflows continue to work for new spec creation.
- Documentation or agent configuration reflects the tool availability if applicable.

## Open Questions
- Should edit access be limited only to docs/specs/ files, or granted generally to the spec designer?

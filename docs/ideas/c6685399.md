## Context

The pi-ideas refine flow currently asks the model to ask questions until it can satisfy the structured idea body, but the required output structure includes `## Open Questions`. That framing can make unresolved questions look like an acceptable final outcome rather than something the refinement conversation should actively try to resolve.

As a result, refining an existing idea may preserve answerable items from the existing `## Open Questions` section instead of asking targeted clarifying questions before rewriting the artifact.

## Goal

Update the idea-refinement prompt so it explicitly treats existing open questions as clarification targets before the idea body is rewritten.

A refined idea should keep the canonical idea shape, including `## Open Questions`, but that final section should contain only genuinely unresolved items, deferred decisions, or questions the user cannot answer yet. When all material questions have been answered, the final `## Open Questions` section should be `None.`

## Scope

- Audit the pi-ideas prompt used when refining an existing idea.
- Reword the prompt to distinguish between:
  - clarifying questions asked during the refinement conversation; and
  - the final `## Open Questions` section written into the idea artifact.
- Instruct the model to inspect the existing `## Open Questions` section before rewriting the artifact.
- Require the model to ask targeted questions whose answers would materially change the refined idea.
- Preserve the canonical section order:
  - `## Context`
  - `## Goal`
  - `## Scope`
  - `## Acceptance Sketch`
  - `## Open Questions`
- Ensure the default refinement outcome reduces or eliminates answerable open questions instead of carrying them forward passively.
- Add prompt or behavior regression coverage if the ideas package has prompt tests or snapshots.

## Acceptance Sketch

- Given an existing idea with answerable open questions, the refine flow asks about those questions before rewriting the idea body.
- The prompt no longer suggests that leaving `## Open Questions` populated is sufficient refinement when targeted clarification is possible.
- The rewritten idea body still uses the canonical five section headers in order.
- The final `## Open Questions` section is `None.` when all material questions have been answered.
- Tests, prompt snapshots, or equivalent regression coverage fail if refinement guidance regresses to treating `## Open Questions` as a passive catch-all.

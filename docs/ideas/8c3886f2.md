## Problem

The `define-spec` skill should properly identify and route through the `herdr` multiplexer when it is available.

## Context

`define-spec` has multiplexer detection logic before dispatching the spec-designer subagent. Add or fix coverage so `herdr` is recognized consistently alongside existing mux backends.

## Acceptance criteria draft

- `define-spec` correctly detects `herdr` when it is the active/available multiplexer.
- Detection does not regress existing supported mux backends.
- Add focused tests or fixtures for the detection path.
- User-facing behavior is clear when no supported multiplexer is available.

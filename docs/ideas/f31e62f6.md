## Context

The `@aphotic/pi-flow-ux` border-status renderer currently shows context usage on the lower-right border as the percentage followed by the `used/total` token window. The percentage is the primary signal users care about, while raw token counts are supporting context.

## Goal

Make the context percentage the rightmost lower-right border value and visually de-emphasize the token counts by coloring them like the current working directory.

## Scope

- Change only the border-status renderer; leave the footer renderer unchanged.
- Reorder the lower-right border from `context% used/total` to `used/total context%`.
- Keep the context percentage on the existing emphasized context/accent color.
- Change the current token count and total token count in the border token window to use the same color field/token as the current working directory (`cwd` / muted).
- Keep the `/` separator subdued via the existing symbol color unless implementation findings suggest it should also follow the muted token-count color.
- Keep existing responsive behavior: the token window remains optional and drops before branch/thinking, while model id and context percentage remain mandatory.
- Update border-status comments and README documentation to describe the new order and color emphasis.

## Acceptance Sketch

- Lower-right border renders token counts to the left of the context percentage, e.g. `9.3k/200k 12.3%`.
- The context percentage is the rightmost lower-right value.
- The used and total token counts use the same theme color as the cwd field.
- The percentage remains visually emphasized with the context/accent color.
- Narrow-width behavior still drops the token window before branch/thinking and keeps the context percentage.
- Tests cover token-count color routing, lower-right ordering, and unchanged drop priority.

## Open Questions

- Should the `/` separator between used and total tokens stay on the subdued symbol color, or also switch to the cwd/muted color?

# pi-flow 0.9.0

Release date: 2026-06-10

## Features

- Added `flow.json` as the workflow dispatch source of truth, covering model tiers, cross-provider tiers, provider-to-CLI routing, coordinator model chains, and explicit execution policy.
- Added `/flow:doctor` for active package/version reporting, helper shim and agent symlink alignment checks, pinned/floating package visibility, and managed repair via `--fix` / `--source`.
- Expanded the startup/header UX layer with structured header data/details handling and settings coverage.

## Workflow reliability

- Improved coordinator dispatch so coordinator workflows run through pi with configured model-chain fallback while leaf workers use provider-specific CLI routing.
- Made numerous changes to promote reliable execution of workflow steps
- Upgraded to latest pi-mux-subagents for improved subagent completion and codex support

## Packaging and dependencies

- Updated Pi peer ranges to `>=0.78.0`.
- Updated `@aphotic/pi-mux-subagents` compatibility to `>=0.3.0`.

## Migration notes

- Replace older `model-tiers.example.json` / model-tier setup with `flow.example.json` copied to `~/.pi/agent/flow.json`.
- Review `packages/pi-flow-core/docs/flow-config-setup.md` for the required `flow.json` shape, including `executionPolicy`.
- Run `/flow:doctor` after updating to confirm the active package, helper shim, and bundled agent links are aligned.

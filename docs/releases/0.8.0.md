# pi-flow 0.8.0

Release date: 2026-06-02

## Features

- Consolidated metadata on editor border (model, thinking level, context usage, working directory)
- Updated activity indicator placement and look-and-feel
- Added a minimal startup header
- Replaced `/working` command with `/tui` command which supports configuration of header and activity indicator
- Unified user-facing TUI settings under `tui.json`, replacing `status.json` and `working.json`

#### Minor (Nice to Have)

- **packages/pi-ideas/README.md:61: README overstates placeholder substitution support**
  - **What:** The README says `${idea}` is substituted in `toolDescription` and `promptSnippet`, but registration passes those values through directly (`packages/pi-ideas/extensions/idea.ts:1270-1271`), and the tests assert the literal description override is preserved.
  - **Why it matters:** Consumers may put `${idea}` in static tool metadata expecting runtime expansion that cannot occur because there is no selected idea at registration time.
  - **Recommendation:** Narrow the placeholder-substitution docs to `refinePrompt` and action `prompt`, or explicitly state that tool metadata is static and not idea-specific.
- **packages/pi-ideas/README.md:112-113: Negation rule text is contradictory**
  - **What:** The merge docs first say `{"name":"-build"}` removes an action, then say an action without `prompt` is skipped and parenthetically imply a prompt-less negation is a no-op. The implementation handles negation before prompt validation (`packages/pi-ideas/extensions/config.ts:85-92`), so prompt-less negations do remove actions.
  - **Why it matters:** The documented removal mechanism could be confusing even though later examples use it correctly.
  - **Recommendation:** Reword the second bullet to say prompt is required only for non-negation entries.
